pokehunt for Windows (test build)

1. Install Python from https://www.python.org/downloads/
   In the installer, tick "Add python.exe to PATH".
2. Double-click "1 Check". The first time it sets itself up, which takes a few
   minutes. It clicks nothing: it reads some sample screenshots, looks at your
   screen and moves the mouse a little.
3. Open Roblox, join the Pokemon game, get into a battle, and double-click
   "2 Watch only". It reads and logs encounters but never clicks.
4. When that looks right: "3 Hunt" (it clicks Run, Bag and so on by itself).
   "4 Debug hunt" catches every encounter, then saves: for testing catching.

Keep Roblox on the main screen. Ctrl+Shift+H pauses / resumes.
To stop: close the black window, or fling the mouse into a screen corner.

Everything it does is reported to the developer's debug channel on Discord
(text and some screenshots of the game), so problems can be fixed remotely.
